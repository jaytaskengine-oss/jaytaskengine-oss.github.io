Automation Audit Checklist

Use this before buying software or building an automation. The goal is to find one repetitive workflow with clear rules, predictable inputs, and a human-review path.

1. Capture the task

  • What is the task called?
  • Who performs it?
  • How often does it happen?
  • What starts it?
  • Which systems are involved?
  • What does a successful result look like?

2. Check automation fit

  • The input arrives in a predictable format.
  • The task follows repeatable rules.
  • The output has a predictable destination.
  • Errors are easy to detect.
  • A human can review exceptions.
  • The task happens often enough to justify setup.

3. Map the workflow

Trigger → Inputs → Rules → Decision points → Output → Exception path → Human approval point → Owner → Success metric.

4. Risk review

  • Identify credentials or secrets involved.
  • Do not email passwords, 2FA codes, private keys, or recovery codes.
  • Keep human approval for payments, legal commitments, account changes, or sensitive communication.
  • Keep a manual fallback and log failures.

5. Start smaller

Automate the smallest complete workflow first. Version one does not need every edge case.
