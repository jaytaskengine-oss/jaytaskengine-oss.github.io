# API Integration Demo

A small portfolio demo showing a bounded REST API integration with defensive error handling, retry behavior, and testable request logic.

## What it demonstrates

- Reusable REST API client structure
- JSON request/response handling
- Configurable authorization headers
- Retries for rate limits and transient server errors
- Clear errors for non-success responses
- Dependency injection for easy testing
- Node.js built-in test runner with no external packages

## Run the tests

```bash
npm test
```

This is a self-directed JayTaskEngine portfolio demonstration, not client work.
